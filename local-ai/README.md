# Local AI

This area will contain Automated Acres projects for running useful AI locally instead of depending entirely on cloud services.

Planned topics include:

- local language models
- model serving
- AI agents
- embeddings and retrieval
- RAG systems
- document processing
- reranking
- GPU and CPU inference
- model benchmarking
- offline-first AI workflows
- integration with other homestead services

Projects should explain the tradeoffs between performance, memory use, power consumption, accuracy, privacy, and complexity.

> **Status:** Structure established; projects will be added as they are validated and documented.
