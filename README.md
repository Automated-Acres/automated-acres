# Automated Acres

**Automate. Simplify. Thrive.**

**Modern Homesteading. Intelligent Living.**

Automated Acres is an open-source project exploring how local AI, automation, self-hosted infrastructure, sensors, and intelligent energy management can make a modern homestead more efficient, resilient, understandable, and self-reliant.

This is not about filling a house with cloud-connected gadgets.

The goal is to build technology that serves the property, continues working locally, can be repaired and understood by its owner, and is practical enough for other people to reproduce.

---

## What We're Building

Automated Acres will document and develop projects across several areas:

- **[Local AI](local-ai/)** — locally hosted language models, AI agents, RAG, document processing, and practical AI tools
- **[Proxmox & Self-Hosted Infrastructure](proxmox/)** — Proxmox, Linux, containers, networking, storage, monitoring, and home servers
- **[Home & Property Automation](home-assistant/)** — Home Assistant, sensors, equipment control, alerts, and property-wide automation
- **[Energy](energy/)** — solar, batteries, generators, power monitoring, efficiency, and intelligent load management
- **[Homestead Systems](homestead-systems/)** — irrigation, water, livestock systems, environmental monitoring, and equipment automation
- **[Networking](networking/)** — reliable local networks, VLANs, offline-first systems, and secure remote access
- **[Monitoring & Data](monitoring/)** — Grafana, InfluxDB, Prometheus, telemetry, logging, and long-term system analysis
- **[Sensors](sensors/)** — environmental, equipment, server, power, and property telemetry
- **[Open-Source Tools & Scripts](scripts/)** — repeatable scripts and documentation designed so others can build the same systems
- **[Documentation](docs/)** — repository-wide concepts, standards, and teaching material shared across projects

## Automated Acres Benchmark — AAB

**AAB is currently under active development and is not ready for production use.**

The Automated Acres Benchmark is being developed as a standardized hardware benchmarking and validation system with a strong focus on:

- Performance
- Power consumption
- Performance per watt
- CPU and GPU behavior
- Thermal performance
- Hardware safety
- Repeatable testing
- Human-readable reports and machine-readable results

AAB now has its own **[development area](aab/)** in this repository. Its application-specific development and safety rules are defined separately from the repository-wide rules so unrelated Automated Acres projects do not carry unnecessary benchmark-specific instructions.

## Why Automated Acres Exists

A lot of homestead technology is either:

- dependent on cloud services,
- difficult to repair,
- poorly documented,
- unnecessarily expensive,
- or designed for a suburban smart home rather than a working property.

Automated Acres is an attempt to take a different approach:

**Use technology where it provides real value, keep control local whenever practical, understand how the system works, and document the process well enough that someone else can reproduce it.**

---

## Build → Test → Document → Teach

The projects here are intended to become more than finished scripts.

The process is:

1. Identify a real problem.
2. Build a practical solution.
3. Test it on real hardware.
4. Measure what actually happens.
5. Improve it.
6. Document the commands, scripts, configuration, and reasoning.
7. Turn the finished work into material that others can learn from.

Expect this repository to grow alongside the Automated Acres project.

## Safety

Some Automated Acres projects may involve electricity, batteries, solar equipment, generators, networking, computer hardware, machinery, water systems, or other equipment where incorrect installation or configuration can cause damage or injury.

Documentation and code in this repository are provided for educational and reference purposes. Verify procedures for your own hardware, follow applicable codes and manufacturer requirements, and use qualified professionals where appropriate.
