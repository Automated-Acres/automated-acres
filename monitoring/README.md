# Monitoring & Data

This area will contain Automated Acres projects for collecting, storing, visualizing, and interpreting system and property telemetry.

Planned topics include:

- Prometheus
- InfluxDB
- Grafana
- exporters
- logging
- time-series data
- hardware telemetry
- service health
- long-term trend analysis
- alerting and diagnostics

Monitoring projects should explain what each metric means, how frequently it is collected, and how to distinguish normal variation from a real problem.

> **Status:** Structure established; monitoring projects will be added as they are standardized for public use.
