# Sensors

This area will contain Automated Acres projects for physical and software sensors used across the homestead.

Planned topics include:

- temperature and humidity
- power and energy
- airflow and fan monitoring
- equipment state
- environmental conditions
- server intake and exhaust monitoring
- sensor validation
- calibration
- Home Assistant integration
- telemetry export

Sensor projects should document expected units, update intervals, failure states, calibration assumptions, and how to verify that a reading is trustworthy.

> **Status:** Structure established; sensor projects will be added as hardware and integrations are validated.
