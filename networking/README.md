# Networking

This area will contain Automated Acres projects for reliable, understandable, and secure local networking.

Planned topics include:

- VLANs and network segmentation
- firewall rules
- DNS and filtering
- local service discovery
- remote access
- device isolation
- monitoring
- resilient offline operation
- documentation of network dependencies

Examples must always use fictional addresses and identifiers. Real private infrastructure details must never be committed.

> **Status:** Structure established; network projects will be added after sanitization and reproducibility review.
