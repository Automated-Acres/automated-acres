# Shared Scripts

This area will contain reusable scripts that support more than one Automated Acres project.

A script belongs here when it is broadly useful across the repository rather than specific to one application directory.

Examples may include:

- system information collection
- common Linux setup helpers
- transfer/install helpers
- validation utilities
- backup helpers
- reusable maintenance tools

Application-specific scripts should normally stay with their application so the code and documentation remain together.

All scripts must follow the root repository requirements for safety, idempotency, validation, teaching-oriented documentation, and privacy.

> **Status:** Structure established; shared scripts will be added only when a genuinely reusable need exists.
