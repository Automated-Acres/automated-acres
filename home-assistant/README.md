# Home Assistant

This area will contain Automated Acres projects built around Home Assistant and local property automation.

Planned topics include:

- sensors and telemetry
- dashboards
- alerts and notifications
- equipment monitoring
- automation logic
- energy data
- environmental monitoring
- integration with local AI
- device health and failure detection
- resilient local-first control

Projects should favor clear failure states and should avoid making critical property functions dependent on unnecessary cloud services when a reliable local option exists.

> **Status:** Structure established; integrations will be added after validation and privacy review.
