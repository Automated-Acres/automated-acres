# Proxmox

This area will contain Automated Acres projects for Proxmox VE and the Linux systems that support the homestead infrastructure.

Planned topics include:

- Proxmox installation and host setup
- power-efficiency tuning
- storage and NVMe configuration
- LXC and VM deployment
- GPU access and passthrough
- backups and recovery
- host monitoring
- filesystem maintenance
- networking
- reproducible setup scripts

Documentation should teach what each command changes, how to verify it, and how to reverse it when appropriate.

> **Status:** Structure established; projects will be added as completed work is reviewed and sanitized for public release.
