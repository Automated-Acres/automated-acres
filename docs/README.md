# Documentation

This area is for repository-wide documentation that does not belong to one specific application or project directory.

Potential uses include:

- project architecture
- terminology and concepts
- contribution guidance
- release process
- documentation standards
- cross-project setup information
- security and privacy guidance
- teaching material shared by multiple projects

Whenever documentation belongs naturally beside the code it explains, keep it in that project's own directory instead of moving everything here.

> **Status:** Structure established; repository-wide documentation will grow as common guidance emerges.
